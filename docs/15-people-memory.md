# 人员、记忆与资料生命周期：T06

2026-11-18｜M2 本地实现｜R-040、R-041、R-042、R-045、R-053、R-054。整体 G1/G2 继续建设，当前没有接入识别、语音或外部记忆模型。

## 使用方式

登录后进入“人员与记忆”（/people），可自愿建立本工作空间的本人资料。同一人可同时标记员工、访客和顾客；员工标记仅由已登录账号关联得到，业务角色不会增加后台权限。访客从匿名终端的“我的接待偏好”另行同意用途，不会因填写来访登记就自动创建长期档案，不按姓名、人脸或声音合并到已有员工。

登记时可选 30、90 或 180 天期限。默认关闭个性化、开启免打扰。前台目录只含主动登记的显示称呼、业务角色、资料来源和期限；管理员也不能读取其他人的私人记忆、摘要或导出包。账号关联证明当前账号关系，不证明自述单位或偏好已经过外部核验。

候选记忆可填写称呼、单位、喜欢、避免和交流话题，或引用当前访客已经提交的文字。保存后为 pending；只有本人明确核对，才变为 confirmed。选择“私人”始终不进入接待检索；“接待可用”还需开启个性化。修改已确认内容会先移除检索索引，重新进入待确认，不直接覆盖为事实。

撤回、拒绝、到期会清除条目内容及检索副本。相关个性化旧回复被清除并取消，旧请求缓存不再返回原值。列表显示状态和来源引用，便于理解更正过程。来源原文到期后，已单独授权的确认事实按自己的期限保留，来源编号仍可追溯，不伪造原文仍然存在。

摘要与待办由本人填写并复核，保存来源会话和可选文字引用；当前没有自动大模型摘要。待办可以完成或删除，摘要可删除；它们不会自动发送消息、执行日历事项或并入员工绩效。

## 个性化与适度问候

匿名终端的文字问题涉及偏好、喜好、称呼或记忆时，模拟回复只使用当前服务对象已确认、在授权范围内的公开条目。私人、候选、失效以及其他人的条目不进入上下文。回复保留明确模拟标识，不声称连接了真实大模型。

本人允许个性化且关闭免打扰后，worker 可在终端空闲、没有正在播放的回复、未处于静默时段时，产生一次模拟问候。本次登记最多自动问候一次；冷却规则同样适用于手动检查。问候只使用已确认且允许公开的偏好称呼，不朗读私人资料或其他偏好。会话人工接管、目标版本变化、离场、超时或真实服务未配置时，不生成该模拟问候。

时段使用接待终端所在场所时区；员工设置页的预览使用本工作空间默认场所时区。静默开始与结束相同表示全天静默。用户主动提问仍可得到受控文字回应，免打扰用于限制主动攀谈。

## 来源与权限

访客凭证仅能访问当前会话、当前 focusVersion 绑定的资料。目标变化后旧绑定不可读写；不能把旧目标、系统回复或未归属音频作为记忆来源。当前仅文字可成为会话来源，声纹与真实 ASR 继续由 T37/T38 处理。

本人资料接口：GET/POST /people/self（工作空间必填）、GET /people/:id，以及 settings、facts、facts/decide、notes、notes/control、greet、erase 子路径。前台目录为 GET /people，仅管理员在授权工作空间内可读，且不含私人字段。

访客路径为 /guest/sessions/:id/memory，提供对应的本人操作、search 和 export。操作继续执行 HttpOnly 会话、CSRF、来源、幂等、对象范围及版本校验；界面隐藏按钮不替代服务端规则。具体输入由共享 Zod 契约生成 [OpenAPI](api/openapi.json)。

## 保留、导出与删除

- 未单独登记记忆的匿名接待原文默认 24 小时清理；登记用途后，本次原文最多自登记起保留 30 天。
- 摘要、待办最长 30 天，记忆不得超过本人资料授权期限；资料期限到期会执行同类清理。
- 来访姓名、单位、事由、预约引用和内部备注在创建后 30 天清理；保留最小处理状态。该默认值用于本地设计，正式试点另按具体业务核定。
- 本人导出包含资料、候选/确认事实、摘要待办，以及仍在保留期内的本人会话；不含他人数据、接待内部备注或登录凭据。
- 删除本人资料会清理有效主库资料、索引、相关原文、会话绑定和敏感幂等响应。相关来访个人字段被遮蔽，待发通知被取消，未完成来访交由人工处理。已提交渠道消息不能假装撤回。
- 删除保存最小回执、审计编号及必要业务状态。当前没有外部记忆服务，外部删除状态为 not_applicable；不代表未来供应商或生产备份已经清理。

清理由 API 访问时和 worker 每分钟执行，读接口不会把到期内容重新返回。幂等记录保留哈希与删除标记，重放被清理的响应返回 DATA_REMOVED，既避免重新暴露内容，也不将旧业务动作当作新动作执行。当前没有独立向量库或模型记忆缓存，实际检索索引为 SQLite 派生表。

SQLite 逻辑清理、生产 PostgreSQL、备份生命周期和未来供应商侧删除分开验收。T20/M6 的生产部署、加密、备份恢复及治理仍待实施，R-053/R-054 的生产部分不标完成。
